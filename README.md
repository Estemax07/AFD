Programa en Python que simula un Automata Finito Determinista (AFD)

El automata SOLO acepta cadenas binarias que comienzan con 0

Ejecutar:
python3 AFD.py Entrada.txt

El archivo tiene una cadena por linea (10 lineas segun requerimientos)


El programa imprime por consola:

ACEPTA
NO ACEPTA
